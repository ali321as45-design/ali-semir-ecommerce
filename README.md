# Ali Semir E-Commerce

Türkiye'nin en modern ve kullanıcı dostu e-ticaret platformu.

## 🌟 Özellikler

- ✅ Responsive ve modern tasarım
- ✅ Ürün katalogı ve filtreleme
- ✅ Sepet yönetimi
- ✅ Smooth animasyonlar
- ✅ Hakkında ve İletişim sayfaları
- ✅ Mobile-friendly arayüz

## 🚀 Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/ali321as45-design/ali-semir-ecommerce.git
cd ali-semir-ecommerce
```

2. Bağımlılıkları yükleyin:
```bash
npm install
```

3. Geliştirme sunucusunu başlatın:
```bash
npm start
```

4. Tarayıcıda açın:
```
http://localhost:3000
```

## 📦 Prodüksiyon Derlemesi

```bash
npm run build
```

## 🛠️ Teknolojiler

- **React 18** - UI Framework
- **React Router v6** - Sayfalar arası navigasyon
- **CSS3** - Tasarım ve animasyonlar
- **JavaScript ES6+** - Programlama dili

## 📱 Sayfalar

### Anasayfa (Home)
- Hoş geldin mesajı
- Özellikler gösterimi
- Call-to-action düğmeleri

### Ürünler (Products)
- Ürün listesi
- Sepete ekleme
- Responsive grid layout

### Sepet (Cart)
- Ürün yönetimi
- Miktar ayarlama
- Toplam fiyat hesaplaması

### Hakkında (About)
- Şirket bilgileri
- İstatistikler
- Misyon ve vizyon

### İletişim (Contact)
- İletişim formu
- Adres bilgileri
- Telefon ve e-mail

## 🎨 Tasarım

- Renk Paleti: Mor (#667eea) & Açık Mor (#764ba2)
- Font: Segoe UI, Tahoma, Geneva
- Responsive Breakpoint: 768px
